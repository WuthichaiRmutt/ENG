# Clone Website & Reverse Engineering Skill

Use this skill to extract, dissect, and clone UI designs, interactive widgets, color palettes, and full layouts from popular web applications into our project.

## Workflow

1. **Inspection & Extraction**:
   - Analyze target URL or screenshots (e.g., PrepEdu, Duolingo, Memrise, TOEFL/IELTS test centers).
   - Identify signature layout patterns:
     - Split-screen test panels (Reading Passage on Left, Question Matrix on Right).
     - Question Number Palette (Grid of questions with color-coded status: Answered, Flagged, Unanswered).
     - Virtual Speaking / Audio wave interfaces.
     - Diagnostic score analytics & band predictors.

2. **Design Token Mapping**:
   - Extract primary, secondary, and accent colors.
   - Extract typography hierarchy (headings, mono timer, badge fonts).
   - Extract elevation, borders, and backdrop-blur styling.

3. **Component Synthesis**:
   - Build modular React + Tailwind CSS components mirroring the target app.
   - Integrate with client-side reactive state, audio synthesis, and scoring engines.
